# 나만의 프롬프트 관리 프로그램

그동안 여러 미션에서 작성한 프롬프트를 한곳에서 관리하는 Python 콘솔 프로그램입니다.
프롬프트를 카테고리별로 분류하고, 키워드로 검색하고, 자주 쓰는 프롬프트는 즐겨찾기로 모아볼 수 있습니다.

## 실행 환경

- Python 3.10 이상
- 외부 라이브러리 없음 (표준 문법만 사용)

## 실행 방법

```bash
git clone https://github.com/steelreto/prompt-manager.git
cd prompt-manager
python prompt_manager.py
```

실행하면 메뉴가 표시되고, 번호를 입력해 기능을 선택합니다. `0`을 입력하면 종료됩니다.

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 새 프롬프트를 등록합니다. 빈 값은 다시 입력받습니다. |
| 2 | 프롬프트 목록 | 저장된 모든 프롬프트를 번호, 카테고리, 즐겨찾기(⭐)와 함께 출력합니다. |
| 3 | 카테고리별 조회 | 카테고리를 선택하면 해당 카테고리의 프롬프트만 출력합니다. |
| 4 | 프롬프트 검색 | 키워드가 제목 또는 내용에 포함된 프롬프트를 찾습니다. |
| 5 | 프롬프트 상세 보기 | 번호를 입력하면 제목, 카테고리, 즐겨찾기 여부, 전체 내용을 보여줍니다. |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기를 추가하거나 해제합니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 보여줍니다. |
| 0 | 종료 | 프로그램을 종료합니다. |

> 추가한 프롬프트와 즐겨찾기 상태는 프로그램 실행 중에만 유지되며, 종료하면 초기화됩니다.

## 프롬프트 카테고리

| 카테고리 | 설명 |
|---|---|
| 텍스트 생성 | 글쓰기, 요약, 이메일 등 텍스트 결과물을 만드는 프롬프트 |
| 이미지 생성 | 이미지 생성 AI에 넣는 장면·스타일 묘사 프롬프트 |
| 영상 생성 | 영상 스크립트, 영상 생성 AI용 프롬프트 |
| 페르소나 | AI에게 특정 역할이나 전문가 성격을 부여하는 프롬프트 |
| 자동화 | 반복 작업을 처리하기 위한 정형화된 프롬프트 |
| 기타 | 위 분류에 속하지 않는 프롬프트 |

## 기본 등록 프롬프트

프로그램 시작 시 이전 미션에서 작성한 프롬프트 5개가 기본으로 등록되어 있습니다.

- [텍스트 생성] 블로그 글 작성 도우미 ⭐
- [이미지 생성] 제품 썸네일 생성
- [페르소나] IT 컨설턴트 페르소나
- [자동화] 뉴스 요약 프롬프트
- [영상 생성] 광고 스크립트 작성
